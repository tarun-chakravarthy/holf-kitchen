# Kitchen Stock Sheet

A simple stock-take and order-list tool for the kitchen: track current vs. required
quantities per item, see an at-a-glance status gauge, and generate a shareable order
list (copy as text or export as CSV).

## Stack

- [Vite](https://vite.dev) + [React](https://react.dev) + TypeScript
- No backend — inventory is saved to the browser's `localStorage`

## Getting started

```bash
npm install
npm run dev
```

Then open the printed local URL in your browser.

## Build

```bash
npm run build
npm run preview
```
